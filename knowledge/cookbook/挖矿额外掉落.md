# 挖矿额外掉落

**目标**：用 `ruby_pickaxe` 挖 `ruby_ore` 时，额外掉一颗 `ruby`。

这类「工具自带某个效果、和附魔可叠加」的机制，原版没有对应事件，只能靠方块破坏事件自己加。

## 代码

锚点 `init`：

```java
net.fabricmc.fabric.api.event.player.PlayerBlockBreakEvents.AFTER.register(
        (world, player, pos, state, blockEntity) -> {
            if (world.isClientSide()) {
                return;
            }
            if (!(player instanceof net.minecraft.server.level.ServerPlayer sp)) {
                return;
            }
            var held = sp.getMainHandItem();
            if (held.isEmpty()) {
                return;
            }
            var toolKey = net.minecraft.core.registries.BuiltInRegistries.ITEM.getKey(held.getItem());
            if (!id("ruby_pickaxe").equals(toolKey)) {
                return;
            }
            var blockKey = net.minecraft.core.registries.BuiltInRegistries.BLOCK.getKey(state.getBlock());
            if (!id("ruby_ore").equals(blockKey)) {
                return;
            }
            var holder = net.minecraft.core.registries.BuiltInRegistries.ITEM.get(id("ruby"));
            if (holder.isEmpty()) {
                return;
            }
            sp.drop(new net.minecraft.world.item.ItemStack(holder.get().value(), 1),
                    false, net.minecraft.util.Prediction.SERVER_ONLY);
        });
```

## 为什么这么写

**用 `AFTER` 不用 `BEFORE`**：`BEFORE` 时方块还没挖掉，这时候掉东西会在破坏失败的情况下也掉（比如玩家中途松手）。`AFTER` 是「确定挖掉了」之后。

**判 `world.isClientSide()`**：方块破坏事件两端都会触发，不判会掉两份。

**`BLOCK.getKey(state.getBlock())`**：注意是 `BLOCK` 注册表不是 `ITEM`。方块和它的 BlockItem 是两个不同的注册项，id 一样但不是同一个对象。

**`state.getBlock()` 而不是 `pos` 位置的方块**：事件给的 `state` 就是被破坏那一刻的状态，更准（有些方块被破坏时状态已经变了）。

## 验证

拿镐子挖矿，每次多掉一颗。换别的镐子或者挖别的方块都不掉。

## 变体

**「自带时运」**：按倍率掉

```java
int extra = 1 + sp.getRandom().nextInt(2);   // 1~2 个
sp.drop(new net.minecraft.world.item.ItemStack(holder.get().value(), extra),
        false, net.minecraft.util.Prediction.SERVER_ONLY);
```

**「自带精准采集」**：方块本体直接进背包

```java
sp.getInventory().add(new net.minecraft.world.item.ItemStack(state.getBlock().asItem(), 1));
```

**换成任意工具都能触发**：删掉 `toolKey` 那一段判断。

**按方块标签判**（比如「所有矿石都吃」）：

```java
if (!state.is(net.minecraft.tags.BlockTags.COAL_ORES)
        && !state.is(net.minecraft.tags.BlockTags.IRON_ORES)) {
    return;
}
```

## 注意

这个事件给的是**方块被破坏之后**，如果同一 tick 有别的 mod 也在处理掉落，先后顺序不保证。要精确控制掉落物，得走战利品表或者 mixin 到 `Block.dropResources`。
