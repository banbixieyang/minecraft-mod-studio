# 击杀掉落奖励

**目标**：用某把剑击杀生物时，额外掉一颗材料。

## 代码

锚点 `init`：

```java
net.fabricmc.fabric.api.entity.event.v1.ServerLivingEntityEvents.AFTER_DEATH.register(
        (entity, source) -> {
            if (!(source.getEntity() instanceof net.minecraft.server.level.ServerPlayer killer)) {
                return;
            }
            // 只对特定武器生效 —— 不需要就删掉这一段
            var held = killer.getMainHandItem();
            if (held.isEmpty()) {
                return;
            }
            var key = net.minecraft.core.registries.BuiltInRegistries.ITEM.getKey(held.getItem());
            if (!id("ruby_sword").equals(key)) {
                return;
            }
            var holder = net.minecraft.core.registries.BuiltInRegistries.ITEM.get(id("ruby"));
            if (holder.isEmpty()) {
                return;
            }
            killer.drop(new net.minecraft.world.item.ItemStack(holder.get().value(), 1),
                    false, net.minecraft.util.Prediction.SERVER_ONLY);
        });
```

## 为什么这么写（两个 26.3 的坑）

**`BuiltInRegistries.ITEM.get()` 返回的是 `Optional<Reference<Item>>`，不是 `Item`。**
所以要 `isEmpty()` 判空，再 `.get().value()` 取值。这是 26.3 最容易写到编译不过的一处。

**`LivingEntity.spawnAtLocation(...)` 已经没有了。**
现在用 `drop(ItemStack, boolean 是否打散, Prediction)`。最后一个参数是枚举 `net.minecraft.util.Prediction`，值有 `PREDICTED`（客户端预测）和 `SERVER_ONLY`（只在服务端）。掉东西一律用 `SERVER_ONLY`，否则可能掉两份。

**`source.getEntity()` 可能是 null**（摔死、饿死、掉岩浆），所以 `instanceof` 判断本身就兼做了非空检查。

## 验证

拿剑砍一只僵尸。地上应该多出 1 个 `ruby`，在击杀者脚下。空手砍不掉东西。

## 变体

**按生物类型给不同奖励**：

```java
if (entity instanceof net.minecraft.world.entity.monster.zombie.Zombie) {
    // 僵尸额外掉点别的
}
```

**给经验**：

```java
killer.giveExperiencePoints(10);
```

**概率掉落**：

```java
if (killer.getRandom().nextFloat() < 0.25F) {   // 25%
    // 掉落
}
```

**直接进背包**（不掉地上）：

```java
killer.getInventory().add(new net.minecraft.world.item.ItemStack(holder.get().value(), 1));
```
注意 `add` 背包满了会丢，重要奖励还是掉地上更稳。
