# 持续光环（附近玩家吃 buff）

**目标**：主手拿着 `ruby_charm` 时，周围 8 格内的玩家持续获得「生命恢复 I」。

## 前置

- 一个物品条目，例如 `ruby_charm`

## 代码

锚点选 `init`：

```java
net.fabricmc.fabric.api.event.lifecycle.v1.ServerTickEvents.END_SERVER_TICK.register(server -> {
    // 每 40 tick（2 秒）扫一次。每 tick 扫会很卡，而且没必要 ——
    // 效果本来就持续几秒，2 秒补一次刚好接得上
    if (server.getTickCount() % 40 != 0) {
        return;
    }
    for (net.minecraft.server.level.ServerPlayer holder : server.getPlayerList().getPlayers()) {
        var held = holder.getMainHandItem();
        if (held.isEmpty()) {
            continue;
        }
        var key = net.minecraft.core.registries.BuiltInRegistries.ITEM.getKey(held.getItem());
        if (!id("ruby_charm").equals(key)) {
            continue;
        }
        var area = holder.level().getEntitiesOfClass(
                net.minecraft.world.entity.player.Player.class,
                holder.getBoundingBox().inflate(8.0),
                p -> p instanceof net.minecraft.server.level.ServerPlayer);
        for (net.minecraft.world.entity.player.Player p : area) {
            if (!(p instanceof net.minecraft.server.level.ServerPlayer target)) {
                continue;
            }
            target.addEffect(new net.minecraft.world.effect.MobEffectInstance(
                    net.minecraft.world.effect.MobEffects.REGENERATION,   // 效果
                    100,                                                  // 持续 tick（5 秒）
                    0,                                                    // 等级：0 = I 级
                    true,                                                 // 环境效果（粒子少）
                    true));                                               // 显示图标
        }
    }
});
```

## 为什么这么写

**每 40 tick 扫一次**：`END_SERVER_TICK` 每秒跑 20 次。每次都遍历所有玩家 + 做范围查询，玩家一多就掉帧。2 秒一次完全够用 —— 效果本身持续 5 秒，补得上。

**`holder.level()`** 拿维度再查实体，不要用 `server.getAllLevels()` 手遍历。范围查询自带 AABB 优化。

**`inflate(8.0)`** 是以玩家碰撞箱为基础往外撑 8 格。想要「球形 8 格」得自己算距离，但玩家实际感知差不多。

**`isClientSide` 不用判**：`ServerTickEvents` 只在服务端跑。

## 验证

拿物品在主手，附近拉个朋友（或者开两个客户端）。两个人身上都会出现生命恢复图标，拿开物品 5 秒后消失。

## 变体

**只给自己**：去掉范围查询，直接 `holder.addEffect(...)`。

**给自己和队友但排除敌对生物**：把 `Player.class` 换成 `LivingEntity.class`，再加个判断 `p instanceof net.minecraft.world.entity.monster.Enemy` 就排除。

**用负面效果**（比如「时之钟」那种减速场）：

```java
net.minecraft.world.effect.MobEffects.SLOWNESS, 60, 1, true, true
```

第三个参数 `1` 是 II 级。等级是从 0 开始算的。
注意 26.3 的字段叫 `SLOWNESS`，不是老教程里的 `MOVEMENT_SLOWDOWN`。

**数值化**：想让强度随距离衰减，就在循环里按 `holder.distanceTo(p)` 算等级，别写死。
