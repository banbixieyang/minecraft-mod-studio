# 攻击附加效果

**目标**：用 `ruby_sword` 打中生物时，让它烧起来 5 秒。

「非附魔机制」类 mod 的核心就是这个套路 —— 不走附魔系统，走伤害事件。

## 代码

锚点 `init`：

```java
net.fabricmc.fabric.api.entity.event.v1.ServerLivingEntityEvents.AFTER_DAMAGE.register(
        (entity, source, base, taken, blocked) -> {
            if (!(source.getEntity() instanceof net.minecraft.server.level.ServerPlayer attacker)) {
                return;
            }
            var held = attacker.getMainHandItem();
            if (held.isEmpty()) {
                return;
            }
            var key = net.minecraft.core.registries.BuiltInRegistries.ITEM.getKey(held.getItem());
            if (!id("ruby_sword").equals(key)) {
                return;
            }
            entity.setRemainingFireTicks(100);   // 100 tick = 5 秒
        });
```

## 为什么这么写

**用 `AFTER_DAMAGE` 不用 `ALLOW_DAMAGE`**：
- `ALLOW_DAMAGE` 是「允不允许这次伤害」，返回值决定伤害是否发生。想改伤害数值、想取消伤害用它。
- `AFTER_DAMAGE` 是「伤害已经发生了」，这时候加 debuff、回血、触发连锁都行。

**`source.getEntity()` 是攻击者，不是挨打的那个。** `entity` 才是挨打的。

**`setRemainingFireTicks(100)`** 直接设置剩余燃烧时间（tick）。目标是 `LivingEntity`（`AFTER_DAMAGE` 的 `entity` 就是这个类型），所以这个方法直接可用。

## 验证

砍僵尸，僵尸身上应该着火。注意：僵尸本来就可能因为白天着火，测的时候挑地下的怪或者晚上测。

## 变体

**吸血**（打多少回多少的一半）：

```java
attacker.heal(taken * 0.5F);
```

`taken` 是实际扣掉的血量（已经算过护甲和抗性）。想按原始伤害算就用 `base`。

**额外真实伤害**（穿护甲也照打）：

```java
entity.hurtServer((net.minecraft.server.level.ServerLevel) entity.level(),
        attacker.damageSources().magic(), 4.0F);
```

`magic` 伤害类型基本无视护甲。用 `attacker.damageSources()` 是为了让死亡消息显示成「被某某击杀」。

**附加凋零**：

```java
entity.addEffect(new net.minecraft.world.effect.MobEffectInstance(
        net.minecraft.world.effect.MobEffects.WITHER, 200, 0, true, true));
```

**只在暴击时触发**：

```java
if (!attacker.fallDistanceExempt()) {
    return;
}
```

（暴击的准确判定比较复杂，`fallDistanceExempt` 只是近似。要精确得 mixin 到 `Player.attack`。）

**按目标类型区分**：

```java
if (entity instanceof net.minecraft.world.entity.monster.Enemy) {
    // 只对敌对生物生效
}
```

## 注意

`AFTER_DAMAGE` 里改血量是安全的（伤害已经结算完），但**不要在里面再触发一次攻击** —— 会递归。

要做「连锁伤害」，先把目标收集起来，下一 tick 再打：

```java
server.execute(() -> { /* 下一 tick 执行 */ });
```
