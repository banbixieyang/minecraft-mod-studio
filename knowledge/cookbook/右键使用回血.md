# 右键使用回血

**目标**：右键点某个物品，回 4 点血，进 5 秒冷却。

## 前置

- 一个物品条目，例如 `ruby_charm`（类型选「普通物品」就行）

## 步骤

1. 「物品」标签里建 `ruby_charm`，中文名「红宝石护符」
2. 「代码」→ 新增 Java 钩子，锚点选 **`init`**
3. 把下面整段贴进去
4. 生成 → 构建

## 代码

```java
net.fabricmc.fabric.api.event.player.UseItemCallback.EVENT.register((player, world, hand) -> {
    if (world.isClientSide()) {
        return net.minecraft.world.InteractionResult.PASS;
    }
    if (!(player instanceof net.minecraft.server.level.ServerPlayer sp)) {
        return net.minecraft.world.InteractionResult.PASS;
    }
    var stack = sp.getItemInHand(hand);
    if (stack.isEmpty()) {
        return net.minecraft.world.InteractionResult.PASS;
    }
    var key = net.minecraft.core.registries.BuiltInRegistries.ITEM.getKey(stack.getItem());
    if (!id("ruby_charm").equals(key)) {
        return net.minecraft.world.InteractionResult.PASS;
    }
    // 冷却判断：物品自带的冷却，客户端会画那个白圈
    if (sp.getCooldowns().isOnCooldown(stack)) {
        return net.minecraft.world.InteractionResult.FAIL;
    }
    if (sp.getHealth() >= sp.getMaxHealth()) {
        return net.minecraft.world.InteractionResult.FAIL;
    }
    sp.heal(4.0F);
    sp.getCooldowns().addCooldown(stack, 100);   // 100 tick = 5 秒
    return net.minecraft.world.InteractionResult.SUCCESS;
});
```

## 为什么这么写

**先判 `world.isClientSide()`**：右键会在客户端和服务端各触发一次。不判会导致「回两次血」。

**判 `isEmpty()` 再取值**：空手右键也会走这个事件，不判会 NPE。

**用 `getCooldowns()` 而不是自己算时间**：物品自带冷却会显示成物品栏上的白圈遮罩，玩家能看见还剩多久。自己用 tick 计数是没有这个反馈的。

**返回 `FAIL` 而不是 `PASS`**：`PASS` 会让原版继续处理（可能触发放置方块、用掉物品），`FAIL` 直接拦掉。冷却中或者血满的时候，你不想让它顺带做别的事。

**返回 `SUCCESS`**：告诉原版「我处理了，别再管」。

## 验证

进游戏，`/give @s <你的id>:ruby_charm`，拿在主手右键：
- 血量应该 +2 颗心
- 物品栏上出现白色冷却圈，5 秒内再点没反应
- 满血时点也没反应

## 变体

**消耗品**（用完就少一个）：

```java
stack.shrink(1);
```

放在 `sp.heal(...)` 后面。注意不要用 `setCount(0)` —— `shrink` 会正确处理空栈。

**扣耐久**（当成有耐久的道具）：

```java
stack.hurtAndBreak(1, sp, net.minecraft.world.entity.EquipmentSlot.MAINHAND);
```

**换个触发条件**（只在潜行时生效）：

```java
if (!sp.isShiftKeyDown()) {
    return net.minecraft.world.InteractionResult.PASS;
}
```
