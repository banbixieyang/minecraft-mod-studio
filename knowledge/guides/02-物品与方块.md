# 物品与方块

「物品」标签里第一条要选的是**类型**。选什么类型决定了下面出哪些字段 —— 表单是跟着变的，看不到某项就是它跟当前类型无关。

## 四种物品类型

| 类型 | 用途 | 会多出的字段 |
|---|---|---|
| 材料 `material` | 纯素材，拿着没用 | 无 |
| 普通物品 `simple` | 能拿能用，但没行为 | 无 |
| 工具 `tool` | 剑、镐、斧、锹、锄 | 工具类型、材质、攻击力、攻速 |
| 盔甲 `armor` | 头盔、胸甲、护腿、靴子 | 装备部位、盔甲材质 |

> 「材料」和「普通物品」生成出来的代码几乎一样。区别只在语义 —— 材料不该被赋予行为，将来编辑器做批量操作（比如「全部材料进某个标签」）时按这个分类认。

## 工具

选「工具」后要填两件关键事：

**工具类型**（`toolType`）：`sword` / `pickaxe` / `axe` / `shovel` / `hoe`。
它决定了生成哪一行代码，也决定了默认攻击力和攻速：

```java
new Item.Properties().rarity(Rarity.COMMON).sword(ModTiers.RUBY, 3.0F, -2.4F)
new Item.Properties().rarity(Rarity.COMMON).pickaxe(ModTiers.RUBY, 1.0F, -2.8F)
```

**材质**（`materialMode`）：

- `preset` —— 直接用原版材质（木/石/铜/铁/金/钻石/下界合金）。适合只想要个「换了皮的原版工具」。
- `custom` —— 用你自己在「工具材质」标签里建的那套数值。这时会出现 `tier` 字段让你选。

不建自定义材质也能做工具，但整套装备的手感会跟钻石一模一样。**建议先建材质再建物品**，这样一次填对。

## 盔甲

选「盔甲」后出现 `armorSlot`（部位）和 `armorMaterial`（盔甲材质）。

盔甲材质在「盔甲材质」标签里建，一次填四个部位各自的防御值。一套盔甲（头/胸/腿/靴）通常共用一个材质 id，比如都叫 `ruby`。

生成出来是这样：

```java
new Item.Properties().rarity(Rarity.COMMON).humanoidArmor(ModArmorMaterials.RUBY, ArmorType.HELMET)
```

> **材质 id 和物品 id 撞了不要紧。** `ruby` 既是材质 id 也是材料物品 id，它们在不同注册表里，互不影响。这也是社区惯例。

## 方块

三种类型：矿石 `ore`、矿物块 `storage`、普通方块 `plain`。

关键字段：

| 字段 | 说明 |
|---|---|
| `hardness` 硬度 | 石头是 1.5，黑曜石 50。挖多久看它 |
| `resistance` 抗爆 | 石头 6，黑曜石 1200。TNT 炸不炸得动看它 |
| `requiresTool` 需要正确工具 | 勾了之后空手挖不掉，必须用镐 |
| `xpMin` / `xpMax` | 挖掉掉多少经验。矿石填 1~3 很常见 |
| `drops` 掉落 | 掉什么、掉几个、吃不吃时运 |

**方块会自动配一个 BlockItem**，所以物品栏里能拿到。它不需要你另外建一个物品条目。

矿石还会自动带上：`data/minecraft/tags/block/ores.json` 之类的标签，让「需要镐挖」这类原版规则生效。

## 贴图从哪来

`texture` 字段有四种模式：

| 模式 | 干什么 | 什么时候用 |
|---|---|---|
| 自动 `auto` | 按 id 里的关键词猜色，生成一张 | 占位，先跑通流程 |
| 原版改色 `recolor` | 拿原版贴图换色相 | **最省事**：剑改红就是红宝石剑 |
| 矿石合成 `ore` | 用石头的纹理 + 矿物色块拼 | 矿石专用 |
| 自己画 `custom` | 用内置画板画，或从 Blockbench 导 | 要认真做素材时 |

改色模式要填「基于哪个原版贴图」和「染成什么色」。底图路径就是原版的，比如 `minecraft:item/diamond_sword`。

**自己画（custom）的贴图会被打包带走** —— 你在「库」里捕获内容时会一起带走。自动改色的不会，因为装到新工程时它应该按新配色重新生成。

## 稀有度和其它

- `rarity`：`common` 白 / `uncommon` 黄 / `rare` 青 / `epic` 紫。只影响名字颜色，不影响强度。
- `stacksTo`：堆叠上限，工具盔甲固定 1，材料一般 64。
- `fireResistant`：防火，掉进岩浆不烧掉。
- `tooltip`：每行一条，生成到语言文件里。支持 `§` 颜色码。

## 常见卡点

**工具做出来挖不动石头**
`incorrectFor` 填错了。这个字段的意思是「挖不动哪一档」，不是「相当于哪一档」。要跟钻石一样就填 `diamond`。

**盔甲穿上去没有防御**
`armorMaterial` 没选，或者选的材质 id 已经被删了。校验会报出来。

**方块挖掉什么都不掉**
`drops` 是空的。空掉落 = 挖了就没，不是默认掉自己。要掉自己就在 `drops` 里加一条，物品填自己的 id。
