# 积木编程入门：手把手搭第一个模组

> **证据等级 `verified-26.3`**：本文的每一步都在本机跑通过 ——
> 界面上搭的程序真跑 Gradle 编译过（Fabric 26.3 和 Forge 1.20.1 都过）。

这篇是给**第一次用**的人看的。不用会编程，照着做就行。

---

## 0. 先说一句：不用写代码

顶栏点「**积木**」，用拖积木的方式写模组逻辑。
写出来的东西**是真 Java**，跟手写的类一样参与构建 —— 不是玩具。

如果你不想读文章，**直接点顶栏「积木」→ 右上角「❓ 入门」**，
界面里有个向导会一步步带你做，还能替你点。

---

## 1. 认识三个地方

```
┌────────────┬────────────────────────────┬──────────────┐
│  积木盒     │          画布                │   右边        │
│            │                            │              │
│ 事件 6 条   │  ┌── 当玩家每 tick 时 ──┐   │  编译预览     │
│ 玩家 9 条   │  └── 对玩家说：___ ▾ ──┐   │  （真 Java）  │
│ 流程 4 条   │                       │   │              │
│ ...        │  ┌ 如果 [假] 那么 ───┐ │   │  工程概览     │
│            │  │  给玩家 5 点生命   │ │   │              │
│            │  └──────────────────┘ │   │              │
│            │                       └───┘              │
└────────────┴────────────────────────────┴──────────────┘
```

| 位置 | 干什么 |
|---|---|
| 左 · 积木盒 | 所有能用的积木，按分类收着。**点一下**加到画布，也能**拖** |
| 中 · 画布 | 你的程序。点积木上的白框改内容 |
| 右 | 你写的这段东西**编译出来是什么 Java**，改一下立刻能看到 |

## 2. 11 步搭出第一个模组

界面里的向导就是照这个顺序做的。

### 第 1 步：认识三个地方

看上面那张图就行。

### 第 2 步：程序总得有个开头

开头叫「**事件**」—— 就是在问「**什么时候**做这件事」。

点左边的「事件」分类，里面有 6 条：

| 事件 | 什么时候触发 |
|---|---|
| 当玩家右键方块时 | 玩家对着方块按右键 |
| 当玩家攻击生物时 | 玩家打怪 |
| 当玩家每 tick 时 | 游戏每走一小步（**一秒钟大概 20 次**） |
| 当服务器每 tick 时 | 整个服务器每走一小步 |
| 当玩家破坏方块时 | 玩家挖掉方块 |
| 当玩家使用物品时 | 玩家右键使用东西 |

### 第 3 步：加一个事件

点「当玩家每 tick 时」→ 画布上出现一个**帽子**。一段新程序的起点。

### 第 4 步：帽子下面是做事的地方

事件只回答「什么时候」，还得有「**做什么**」。
做事的积木在「玩家」分类里。

### 第 5 步：让玩家说句话

点「对玩家说」→ 它接到帽子下面了。

### 第 6 步：换成你想说的话

积木上的**白色小框**就是能改的地方。点进去，把字删掉，换成你自己的话。

> 改完立刻生效：右边的编译预览马上会变。
> （这里以前有个坑 —— 早期版本改完一重绘，字就没了。现在不会。）

### 第 7 步：「如果」能装一整块

有些事只在特定时候做，就用「**如果…那么**」（在「流程」分类里）。

它下面有个**凹槽**，能再塞进别的积木 —— 凹槽里的积木只有在条件成立时才做。

### 第 8 步：把「治疗」放进凹槽

在凹槽里放一条「给玩家 %amount 点生命」，凹槽里就多了一条积木。

条件位默认是「**假**」，点那个小按钮能切「真 / 假」。
要做复杂判断，往条件位里拖一条条件积木（比如「10 < 5」）。

### 第 9 步：看看变成了什么代码

右上角点「**编译预览**」，右边立刻出现真正的 Java：

```java
public static void on_player_tick(
        net.minecraft.server.level.ServerPlayer player,
        net.minecraft.world.level.Level level) {
    player.sendSystemMessage(
            net.minecraft.network.chat.Component.literal("你好呀！"), false);
    if (false) {
        player.heal(5);
    }
}
```

### 第 10 步：存下来

点「**保存**」，程序存进这个工程。
以后「生成」和「构建 jar」都会把它一起编译进去。

### 第 11 步：你已经会搭积木了

现在可以试这些：

- 换别的**事件**，看看哪些适合你的模组
- 从「数学与变量」里拖一条运算，放进「对玩家说」的参数槽
- 点顶栏「**代码造积木**」，把一段 Java 变成自己的积木
- 点顶栏「**积木库**」，看看已经有 186 条现成积木（三个 Goety 模组的）

## 3. 界面里的「入门向导」

不想读文章的话：

1. 顶栏点「**积木**」
2. 工具条点「**❓ 入门**」
3. 左边最上面出现一个紫色面板

每一步都有：

| 元素 | 作用 |
|---|---|
| 进度点 | 点哪个跳到哪一步（共 11 步）|
| **带我做** | **向导替你在界面上操作这一步** —— 展开分类、加上积木、填上示例 |
| 上一步 / 下一步 | 自己走 |
| ✕ | 收起面板 |

「带我做」是真的会操作界面的：它会展开对应分类、把积木真的加到画布上、
把示例文字真的填进输入框。你也可以做完再改成自己的。

> ⚠️ **生成区会被覆盖。** 手写代码请写到别的类里，或者把逻辑拆成多个积木程序。

## 4. 四种积木形状

| 形状 | 长什么样 | 例子 |
|---|---|---|
| 帽形 | 上面有个圆弧 | 当玩家每 tick 时 |
| 语句 | 长条 | 对玩家说 |
| 条件 | 六边形 | 10 < 5 |
| 值 | 椭圆 | 玩家当前生命值 |

**语句**能接在语句下面，也能放进容器槽。
**条件**和**值**只能塞进槽里（不能自己站在画布上）。

## 5. 常见问题

**Q：积木拖不进去？**
A：槽有类型。文本槽只放文本，条件槽放条件积木，语句链只放语句积木。
放错会提示「这个位置放不下」。

**Q：为什么有条积木是灰的？**
A：那条积木在当前目标下还没有实现。切到支持它的目标
（Fabric 26.3 / Forge 1.20.1）看看。

**Q：改过的字保存后没了？**
A：不会。改完立刻写进模型，点「保存」或「编译预览」都对。

**Q：生成的 Java 在哪？**
A：`src/main/java/<包名>/custom/ModLogic.java`。

**Q：能用积木做复杂逻辑吗？**
A：积木适合「什么时候 → 做什么」这类逻辑。
要非常精细的控制，还是手写 Java 更好 —— 两者可以混着来，最后都在同一个 jar 里。
