# 26.3 物品属性与装备

## Item.Properties 链式方法

一个物品的属性就是 `new Item.Properties()` 后面一路点下去，最后交给 `Item` 构造器：

```java
new Item.Properties()
        .setId(key)            // 必须：注册 key
        .stacksTo(64)          // 堆叠上限
        .rarity(Rarity.RARE)   // 名字颜色
        .fireResistant()       // 防火
```

| 方法 | 说明 |
|---|---|
| `setId(ResourceKey<Item>)` | **26.3 必填**，漏了运行时 NPE |
| `stacksTo(int)` | 默认 64；工具盔甲会被装备方法自动改成 1 |
| `rarity(Rarity)` | `COMMON` / `UNCOMMON` / `RARE` / `EPIC` |
| `fireResistant()` | 掉进岩浆不烧 |

> 1.20.1 的 `Item.Properties` 没有 `setId`。写了会编译不过 —— 别把老教程的代码直接抄过来。

## 工具：方法名就是工具类型

26.3 的装备是**组件式**的：属性方法直接把物品变成工具，不再需要自定义类。

```java
new Item.Properties().rarity(Rarity.COMMON).sword(ToolMaterial, 攻击力, 攻速)
new Item.Properties().rarity(Rarity.COMMON).pickaxe(ToolMaterial, 攻击力, 攻速)
new Item.Properties().rarity(Rarity.COMMON).axe(ToolMaterial, 攻击力, 攻速)
new Item.Properties().rarity(Rarity.COMMON).shovel(ToolMaterial, 攻击力, 攻速)
new Item.Properties().rarity(Rarity.COMMON).hoe(ToolMaterial, 攻击力, 攻速)
```

默认数值（跟原版钻石档对齐，编辑器不填就用这套）：

| 类型 | 攻击力 | 攻速 | 原版对照 |
|---|---|---|---|
| `sword` | 3.0 | -2.4 | 钻石剑 |
| `pickaxe` | 1.0 | -2.8 | 钻石镐 |
| `axe` | 6.0 | -3.2 | 钻石斧 |
| `shovel` | 1.5 | -3.0 | 钻石锹 |
| `hoe` | -2.0 | 0.0 | 钻石锄 |

攻击力是**加成值**，不是最终伤害。最终伤害 = 1（空手）+ 加成。

## 原版 ToolMaterial 常量

不想自定义材质时直接用：

```java
ToolMaterial.WOOD      ToolMaterial.STONE     ToolMaterial.COPPER
ToolMaterial.IRON      ToolMaterial.GOLD      ToolMaterial.DIAMOND
ToolMaterial.NETHERITE
```

## 自定义 ToolMaterial

```java
public static final ToolMaterial RUBY = new ToolMaterial(
        BlockTags.INCORRECT_FOR_DIAMOND_TOOL,   // 挖不动哪一档方块
        1561,                                   // 耐久
        8.0F,                                   // 挖掘速度
        3.0F,                                   // 攻击伤害加成
        10,                                     // 附魔能力
        ModTags.RUBY_TOOL_MATERIALS);           // 维修材料标签
```

**第一个参数最容易填错**：它是「挖不动什么」，不是「相当于什么」。
- 想要钻石级手感 → `BlockTags.INCORRECT_FOR_DIAMOND_TOOL`
- 想要木级手感 → `BlockTags.INCORRECT_FOR_WOODEN_TOOL`
- 想要铁级 → `BlockTags.INCORRECT_FOR_IRON_TOOL`
- 下界合金 → `BlockTags.INCORRECT_FOR_NETHERITE_TOOL`

参考值（原版）：木 59 耐久 / 2 速度 / 0 加成；铁 250 / 6 / 2；钻石 1561 / 8 / 3；下界合金 2031 / 9 / 4。

## 盔甲

```java
new Item.Properties().rarity(Rarity.COMMON)
        .humanoidArmor(ArmorMaterial, ArmorType.HELMET)
```

`ArmorType` 四个值：`HELMET` / `CHESTPLATE` / `LEGGINGS` / `BOOTS`。

没有 `armorMaterial` 时物品会退化成 `stacksTo(1)` 的普通物品 —— 能拿到、长得像盔甲、**但穿不上**。

## 自定义 ArmorMaterial

```java
public static final ArmorMaterial RUBY = new ArmorMaterial(
        33,                                              // 耐久系数
        Map.of(ArmorType.HELMET, 3, ArmorType.CHESTPLATE, 8,
               ArmorType.LEGGINGS, 6, ArmorType.BOOTS, 3),// 各部位防御
        10,                                              // 附魔能力
        SoundEvents.ARMOR_EQUIP_DIAMOND,                 // 装备音（Holder<SoundEvent>）
        2.0F,                                            // 韧性
        0.0F,                                            // 击退抗性
        ModTags.RUBY_ARMOR_MATERIALS,                    // 维修材料标签
        assetKey);                                       // 外观资源 key
```

`assetKey` 是 26.3 新增的东西，指向盔甲外观资源：

```java
ResourceKey<EquipmentAsset> assetKey =
        ResourceKey.create(EquipmentAssets.ROOT_ID, MyMod.id("ruby"));
```

配套资源文件：

| 文件 | 内容 |
|---|---|
| `assets/<id>/equipment/ruby.json` | 描述这件盔甲用哪张贴图 |
| `assets/<id>/textures/entity/equipment/humanoid/ruby.png` | 头盔/胸甲/靴子 |
| `assets/<id>/textures/entity/equipment/humanoid_leggings/ruby.png` | 护腿（单独一张） |

> 腿的贴图是**另放一张**的。这就是为什么很多 mod 的护腿颜色和别的位置有点不一样。

## 稀有度对照

| 字段值 | 枚举 | 颜色 | 原版例子 |
|---|---|---|---|
| `common` | `Rarity.COMMON` | 白 | 铁锭 |
| `uncommon` | `Rarity.UNCOMMON` | 黄 | 附魔金苹果 |
| `rare` | `Rarity.RARE` | 青 | 钻石 |
| `epic` | `Rarity.EPIC` | 紫 | 下界之星 |

只影响名字颜色，不影响任何属性。

## 带 tooltip 的物品

编辑器生成的 `DescribedItem` 是一个继承 `Item` 的小类，把语言键当额外行显示：

```java
props -> new DescribedItem(props, "tooltip.mymod.ruby_sword.0", "tooltip.mymod.ruby_sword.1")
```

对应语言文件 `item.mymod.ruby_sword.tooltip` 不是它用的键 —— 它用的是 `tooltip.<modid>.<itemid>.<序号>`。这两套别混。
