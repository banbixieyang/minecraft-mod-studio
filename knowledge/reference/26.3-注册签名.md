# 26.3 注册签名速查

> **证据等级 `verified-26.3`**：下面每段代码都是本机 Fabric 26.3 工程实际编译通过的产物，
> 不是从 1.21 文档推的。26.3 官方文档站目前没有版本页，所以这里以实编为准。

## Identifier（原来的 ResourceLocation）

`ResourceLocation` 在 1.21.11 起改名为 `Identifier`，构造器私有，只能用工厂方法：

```java
net.minecraft.resources.Identifier.fromNamespaceAndPath("mymod", "ruby")  // mymod:ruby
net.minecraft.resources.Identifier.parse("mymod:ruby")                    // 从整串解析
```

主类里通常包一个快捷方法，全工程都用它：

```java
public static Identifier id(String path) {
    return Identifier.fromNamespaceAndPath(MOD_ID, path);
}
```

## 物品注册

**26.3 的硬性要求**：key 必须写进 `Item.Properties`，否则运行时抛 `NullPointerException: Item id not set`。

```java
ResourceKey<Item> key = ResourceKey.create(Registries.ITEM, MyMod.id("ruby"));
Item item = new Item(new Item.Properties().setId(key));
Registry.register(BuiltInRegistries.ITEM, key, item);
```

带工厂的通用辅助（生成器用的就是这套）：

```java
private static <T extends Item> T reg(String name,
                                      Function<Item.Properties, T> factory,
                                      Item.Properties props) {
    ResourceKey<Item> key = ResourceKey.create(Registries.ITEM, MyMod.id(name));
    T item = factory.apply(props.setId(key));
    Registry.register(BuiltInRegistries.ITEM, key, item);
    return item;
}
```

> **静态字段的坑**：`public static final Item RUBY = reg(...)` 不会自己执行。
> 必须在 `onInitialize()` 里调用一次 `ModItems.init();` 触发类加载（哪怕是空方法）。

## 方块注册

```java
ResourceKey<Block> key = ResourceKey.create(Registries.BLOCK, MyMod.id("ruby_ore"));
Block block = new DropExperienceBlock(
        UniformInt.of(1, 3),                                  // 掉落经验范围
        BlockBehaviour.Properties.of()
                .setId(key)
                .strength(3.0F, 3.0F)                          // 硬度, 抗爆
                .requiresCorrectToolForDrops()                 // 必须用正确工具
                .sound(SoundType.STONE));
Registry.register(BuiltInRegistries.BLOCK, key, block);
```

方块必须另配 `BlockItem` 才能拿到手上：

```java
ResourceKey<Item> itemKey = ResourceKey.create(Registries.ITEM, MyMod.id("ruby_ore"));
Registry.register(BuiltInRegistries.ITEM, itemKey,
        new BlockItem(block, new Item.Properties().setId(itemKey)));
```

普通方块用 `new Block(props)`，矿石用 `new DropExperienceBlock(UniformInt, props)`。

## 创造栏

26.3 走 Fabric 的构造器，**不是** `CreativeModeTabs.create(...)`：

```java
ResourceKey<CreativeModeTab> MAIN =
        ResourceKey.create(Registries.CREATIVE_MODE_TAB, MyMod.id("main"));

CreativeModeTab tab = net.fabricmc.fabric.api.creativetab.v1.FabricCreativeModeTab.builder()
        .title(net.minecraft.network.chat.Component.translatable("itemGroup.mymod.main"))
        .icon(() -> new ItemStack(ModItems.RUBY))
        .displayItems((params, output) -> {
            for (Item item : ModItems.all()) output.accept(item);
        })
        .build();
Registry.register(BuiltInRegistries.CREATIVE_MODE_TAB, MAIN, tab);
```

往**原版**创造栏里塞东西用事件：

```java
net.fabricmc.fabric.api.itemgroup.v1.ItemGroupEvents
        .modifyEntriesEvent(net.minecraft.world.item.CreativeModeTabs.INGREDIENTS)
        .register(entries -> entries.accept(ModItems.RUBY));
```

## 标签

`ItemTags.create(...)` 已经没有了。现在是：

```java
public static final TagKey<Item> RUBY_TOOL_MATERIALS =
        TagKey.create(Registries.ITEM, MyMod.id("ruby_tool_materials"));

public static final TagKey<Block> NEEDS_RUBY_TOOL =
        TagKey.create(Registries.BLOCK, MyMod.id("needs_ruby_tool"));
```

标签内容写在 `data/<id>/tags/item/<name>.json`：

```json
{
  "values": ["mymod:ruby"]
}
```

## 取注册表里的东西

**这是 26.3 最容易踩的一处**：`get()` 返回的不是物品。

```java
// ✗ 编不过：Optional<Reference<Item>> 不是 Item
Item item = BuiltInRegistries.ITEM.get(MyMod.id("ruby"));

// ✓
var holder = net.minecraft.core.registries.BuiltInRegistries.ITEM.get(MyMod.id("ruby"));
if (holder.isEmpty()) return;
Item item = holder.get().value();
```

反查 id（拿手上的物品问「你叫什么」）：

```java
net.minecraft.resources.Identifier key = BuiltInRegistries.ITEM.getKey(stack.getItem());
```

`getKey()` 返回 `Identifier`，可以直接和自己的 `id("...")` 比。

## 注册时机

注册**必须**发生在 `onInitialize()` 调用链里。放到别处（例如某个事件回调第一次触发时）会报：

```
IllegalStateException: This registry can't create intrusive holders
```

原因是 1.21.2 起注册表在启动完成后就冻结了。
